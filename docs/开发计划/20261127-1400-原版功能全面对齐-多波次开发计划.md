## 目录所有权（硬规则）

只有主控能改：`plugin.toml`、`src/lib.rs`、`Cargo.toml`、`Cargo.lock`、`README.md`、`locales/*.json`、`.github/`。
车道需要新命令 / 能力 / provider / MCP 工具 / 依赖 / 文案时，写 `docs/registration/<lane>.md`，格式见 `docs/ORCHESTRATION.md` §4。

## 门禁

- 车道内：`cargo fmt --all --check` + 只跑本模块定向测试；**改 `web/**` 必跑 `node scripts/check-web-syntax.mjs`**。
- 不跑 clippy、不跑全量、不 `clean`、不 `--stop`。
- 合并点由主控跑：一次 `cargo test`（全 targets）+ `openidea-plugin build && openidea-plugin check .`。
- 权威全量在 CI：推 `ci/gate-<n>` 读结论。

## 红线

- 不 push 业务分支、不建 tag、不发 Release。
- 不复制原版 Kotlin 源码进本仓；只把它当规格。图标 SVG 可复用（Apache-2.0，已在 `NOTICE`）。
- 新增依赖必须许可白名单（Apache/MIT/BSD，禁 GPL）。
- 结果必须带 `exact`/`partial`/`unresolved`；`unresolved` 不出 SQL。
- 1.15 基线：禁用 1.16 的 `frames` / `markdown_hover` / `customEditors.binary`。

## 已知坑（派活时一并交代）

- `web/preview.js` 的 `TEMPLATE` 是跨百行的模板字符串，**内部不能出现反引号或 `${`**，否则整份模块语法错、面板全哑（已有 `check-web-syntax` 拦）。
- 宿主 WebSocket 只走二进制帧；agent 已适配，别改回只认文本。
- 进程级存储的测试必须持 `views::test_state_lock()`；`log_panel::push_state()` 在测试构建里不持锁会 panic。
- 并行构建上限 2 路；跑 `./gradlew` 前查 `parallel_tasks.py`（本仓不用 gradle，但原版仓是只读参考，不要在里面构建）。
