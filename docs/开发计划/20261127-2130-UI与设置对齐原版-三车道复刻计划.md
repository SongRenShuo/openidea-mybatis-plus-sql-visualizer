### 0.1 平台侧结论（决定了本轮的降级口径）

- SDK（v0.1.54 / API 1.18）**只有设置读**（`host::setting_bool/string/number`），**没有写设置、也没有「打开 IDE 设置页」的 API**。设置齿轮无法复刻原版「跳设置页」；本轮改为面板内「设置」弹窗（展示当前值 + 去设置页的路径说明），并写入 `LIMITS`。
- `database` 不执行 SQL：预览「执行 SQL」与「执行计划」真执行仍禁用（既有 LIMITS §3）；本轮只把按钮的存在感、禁用原因、tooltip 对齐原版。
- 设置 schema 支持 `boolean / integer / string / enum` 四种控件；颜色项用 `string` + `#RRGGBB` 说明，原版的颜色选择器不复刻（记 LIMITS）。
- 项目级设置（原版 `ProjectPluginSettings`）平台无对应 contribution，本轮不造；方言等按项目覆盖记 LIMITS。

## 2 前置：共享高亮模块（主控，已完成）

`web/sql-highlight.js`——两个页面共用的 SQL 词法器与渲染器：

- `tokenize(text)` → `{cls, text}[]`，token 类别与原版 `MP_SQL.*` 一一对应（kw/tbl/id/str/num/com/op/paren）；表名启发与 `AS` 别名窗口同原版。
- `into(element, text, limit=20000)` 用 `textContent` 构造 span，超长直接纯文本（日志摘要不会为一条两万字符的语句建几千节点）。
- `installStyles()` 注入 8 条样式，颜色绑宿主 `--openidea-*` 变量（原版绑 scheme key，同一语义策略；日志页「不用字面色」测试继续成立）。
- 自测：6 组词法用例通过（类名序列 + 拼接等于原文）。

### 7.5 各车道登记的实施偏离

L1（预览）：

- meta 的「表」段隐藏（`WorkbenchModel` 无表元数据，不从 SQL 反推）。
- 「语句: {类型}」切换按钮恒隐藏（本渲染无多消费档位模型）。
- 回滚 SQL / 切换数据源 / 导出回放脚本 / AI 上下文（两档）/ 预估影响行数：缺主键元数据、数据源后端、执行通道、脱敏通道、只读 COUNT，置灰并在 title + aria-label 写明原因。
- 预设存储与逐条件值输入：无后端模型，预设控件置灰、条件行只有勾选框。

L2（日志列表）：

- 近似耗时 `~` 前缀：页面已支持 `row.duration_approx`，但标记来自 `core/log` 解析链（不在车道文件所有权内）。
- MCP 紫色角标：CSS 与渲染分支就绪，行模型暂无可用的来源字段。
- DDL 在关键字换行下仍是一行（本仓 `core::format` 不拆 DDL 定义列表）。
- meta 行保留 `[请求 id]`（既有「按请求聚焦」入口）。
- 列表 SQL 字体保留等宽（原版继承 JBList 的 UI 字体；等宽在 SQL 上更易读，作为有意偏离记录）。

L3（设置）：

- 142 项中真正接线的只有日志解析一组（前缀 / 混合前缀 / 过滤关键字 / 耗时前缀 / Hibernate 与 JdbcTemplate 捕获开关），其余在 `DEFINITIONS` 与页面 description 标 `stored, not wired`。
- 快捷键页 5 行为只读文案（平台无录制 API）。
- 关于页的按钮类动作（清缓存 / 报告问题 / 导入导出）写成说明性只读项。
- 颜色项是 `#RRGGBB` 文本（schema 无取色器控件）。
