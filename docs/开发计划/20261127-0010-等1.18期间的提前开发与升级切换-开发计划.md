# 等 1.18 期间的提前开发与升级切换计划

> 立项时间：2026-11-27 00:10。决策依据：`docs/调研报告/20261126-2330-OpenIDEA插件弹窗能力到货验证-调研报告.md`。
> 目标：在不引入任何 1.16+/1.18 清单键的前提下，把**与版本无关的功能**全部做完；等含 1.18 的 tag 发布后，只做一次「版本跳跃 + 弹窗外壳」的薄切换。
> 状态：`已做` / `待做` / `等 1.18`。

## 1 为什么不能提前写 `[[contributes.dialogs]]`

不是保守，是会被拒。`main` 的 `crates/ide-host/src/plugins/ui_points.rs` 里每个 `dialog()` 校验第一件事就是：

```rust
pkg.manifest.needs_api(&format!("contributes.{DIALOGS}"), 18)?;
```

`needs_api`（`crates/ide-extension/src/manifest.rs:317`）的判定是「引擎范围里存在任何小于 1.18 的版本就报错」：

```rust
let older = |m| engine_compatible_with(&self.engine, &semver::Version::new(1, m, u64::MAX));
if self.legacy || (0..minor).any(older) { return Err(format!("… is new in plugin API 1.{minor}: set engines.openidea to \"^1.{minor}\"")); }
```

`engine = "^1.15"` → 报错 → 扩展点 prepare 失败 → 整包不装载。实测 0.1.51 CLI 对同一份清单给出的是 `warning: contributes.dialogs: not supported by this version of the IDE; skipped`，看起来无害；但那是**当前 IDE 不认识这个点**时的降级，一旦宿主认识它，就变成硬错误。两种行为都指向同一结论：**这行只能和 `^1.18` 同一次提交落地。**

同理不提前写的还有：`[[contributes.overlays]]`（同样 `needs_api(18)`）、`frames` / `markdown_hover` / `customEditors.binary`（1.16 面，我们基线禁用）。

## 2 可以提前做的：与版本无关的三类工作

### A 类：先建「弹窗要用的页面与协议」，外壳仍是页签

弹窗与页签用的是同一套东西：一个包内 web 页面 + `openidea.postMessage` / `onMessage` + 宿主的 `post_message` / `refresh_view`。差别只有「谁来承载这个页面」。

所以步骤是：**把预览从「第 5 页签里的一段 DOM」抽成一个独立页面**，先在页签里 `iframe` 承载；1.18 到位后把 `iframe` 换成 `[[contributes.dialogs]]`，逻辑零改动。

| # | 工作 | 交付物 | 判据 |
| --- | --- | --- | --- |
| A1 | 抽出 `web/preview.html`：只保留预览工作台（输入区、参数列、SQL/原文/列信息页签、工具栏），删掉日志面板相关的一切 | 新文件 + `web/log-panel.html` 瘦身 | 两个页面各自 `openidea.onMessage` 只处理自己的 op；预览页在浏览器里能独立渲染出静态骨架 |
| A2 | 预览页与宿主的 op 协议定稿并写进 `docs/registration/L23.md`：`preview-render` / `preview-format` / `preview-load-file` / `preview-clear` / `preview-copy` / `preview-export` / `preview-params` / `preview-rollback` / `preview-mode` / `preview-tab` / `preview-statement` | 协议表（op / 入参 / 出参 / 错误码） | 表里每一行都有对应的 Rust 分支与一条单测 |
| A3 | 宿主侧按 `view id` 路由而不是按「页签」路由：`post_view_message("sqlv-preview", …)` 的调用点集中到一个 `preview_target()` 函数 | `src/views/workbench.rs` | 切换承载方式只改 `preview_target()` 返回值 |
| A4 | 面板与预览之间的「发送到预览」改成跨视图消息（面板 → 宿主 → 预览），不再依赖同一页面内的状态 | `log_panel.rs` + `workbench.rs` | 面板点「快速预览」时预览页独立收到消息 |
| A5 | 页签内承载：`web/log-panel.html` 以 ES 模块 `import` 同一份 `web/preview.js`，把预览挂到第 5 页签 | `web/log-panel.html` + 新 `web/preview.js` | 页签内预览的所有功能与今天等价（逐条对照） |

A5 为什么不是 `iframe`：包页被宿主装进 `iframe sandbox="allow-scripts"` 的**不透明源**里，`window.openidea` 只注入这一层（`plugins/README.md`「The same `openidea` object … is there before the page's scripts run」），
再嵌一层 `preview.html` 的子框架拿不到桥，消息也过不去。文档明确支持的复用方式是**同目录 ES 模块**（「only the page's own files (relative URLs, ES modules, fonts, WebAssembly)」），
所以做法是「一份 `preview.js`，两个挂载点」：`web/preview.html` 独立成页（1.18 给弹窗用），`web/log-panel.html` 里 `import` 同一模块挂到页签。

A 类是纯重构，**在 0.1.53 上就能验完**，也是这次提前开发的主体。

## 3 1.18 发布后的切换清单（薄，一次性）

按顺序，每步都有独立可提交点：

1. `C1` 脚本跑一次：`engines.openidea = "^1.18"`、SDK tag、`CLI_TAG` 三处同步；`cargo test` + `build` + `check` 全绿。
2. `plugin.toml` 加 `[[contributes.dialogs]] id = "sqlv-preview"`（`web = "web/preview.html"`，900×600），并确认 `id` 与 `sqlv-logs` 不冲突（宿主会校验）。
3. `preview_target()` 返回值从「页签」改为 `Reveal::Dialog("sqlv-preview")`；`preview-sql` 命令与 gutter 动作改调 `reveal_view("sqlv-preview")`。
4. 接 `closed` 事件（`ViewEvent::closed()`）：关弹窗后清掉「已推送但未消费」的状态，避免下次打开串味。
5. 页签形态保留：`logs.preview.standaloneTab` 式设置（克隆原版语义）决定「弹窗为主」还是「页签常驻」；默认弹窗，页签仍可从工具窗打开。
6. 验收：Esc 关闭、尺寸记忆（同一对话框第二次打开沿用上次尺寸）、页面 `openidea.dialog.close()`、模态期间主窗口不可交互。
7. 文档：删掉 `LIMITS.md` 第 22 条的「还没有」表述；`ROADMAP.md` 的 P-8 标成立；`CHANGELOG.md` 记一条。

## 5 每条车道的退出门禁

- 车道内：`cargo fmt --all --check` + 本模块定向测试（`cargo test --lib <module>`，集成测试改动的加 `--test <name>`）。
- 合并点：一次 `cargo test`（全 targets）+ 一次 `openidea-plugin build && openidea-plugin check .`。
- 纪律：本仓 CI 跑的是 `clippy --all-targets -D warnings` 与 `cargo test`（全 targets）。只跑 `--lib` 会漏集成测试与 lint——2026-11-26 就是这样把 master 弄红的，不要再犯。

## 6 明确不做的（等 1.18 或永远不做）

| 项 | 原因 |
| --- | --- |
| 提前写 `[[contributes.dialogs]]` / `[[contributes.overlays]]` | 见第 1 节：宿主一旦认识就报硬错，整包装载失败 |

| 1.16 的 `frames` / `markdown_hover` / `customEditors.binary` | 基线禁用，且与弹窗无关 |
| 「执行 SQL」「DML 影响面预演」 | `database` 不执行 SQL，已进 LIMITS，与版本无关 |
| JOIN 图的类型推断 | 无类型解析，已进 LIMITS |
