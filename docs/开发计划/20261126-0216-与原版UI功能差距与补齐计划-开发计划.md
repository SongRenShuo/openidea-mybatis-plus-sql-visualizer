## 5 受平台限制（写进 LIMITS，不排期）

- 无 PSI/类型解析 → 实体字段类型、JOIN 图推断做不了。
- **借 jdtls 也不行**（2026-11-26 复核）：插件能发的 LSP 只允许服务器自有命名空间，`textDocument/*` / `workspace/*` /
  `callHierarchy/*` 等 14 个标准命名空间在宿主侧被拒（`crates/ide-lsp/src/plugin_requests.rs:11-38`），
  `documentSymbol` / `definition` 发不出去。已写入 `docs/LIMITS.md` 第 20 条。
- `database` 不执行 SQL → 「执行 SQL」「DML 影响面预演」不可行。
- 无 Registry 等价物 → 原版「页签开关」这类隐藏设置不做；需要开关时走 setting schema（会动 42 项计数）。
- 读不到运行控制台 → 捕获只能 agent / 导出日志文件（已是现状）。
