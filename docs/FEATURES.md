## 5 优先顺序（决定 P1–P6 排期）

1. **日志还原**（纯文本、低权限、竞品只做编辑器级，我方做项目感知）
2. **XML/注解/iBatis 渲染**（现成档最密集，价值最直接）
3. **方言校验 + 写安全预检 + 回滚计划**（纯逻辑，差异明显）
4. **MCP 11 工具**（市场空白，五家竞品均无）
5. **Wrapper 渲染**（依赖 sidecar 与文本定位，P5）
6. **导航**（已商品化，默认关闭）
