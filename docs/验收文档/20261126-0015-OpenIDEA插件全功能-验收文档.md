## 4 面板验收

### 4.1 SQL 日志（`sqlv-logs`）

> 2026-11-26 复刻后形态：面板是**右侧** ToolWindow（对齐原版侧边栏），页面为包页；自上而下
> 是动作行（暂停 / 清空 / 复制 SQL）、筛选行（SQL 类型多选 / 搜索 / 去重）、列表、状态行。
> 不再有分页，`logs.pageSize` 的语义是「缓冲上限」。

1. 空态：打开面板显示「尚未捕获到 SQL 语句。」，状态行 `共 0 条`。已验。
2. 数据行：加载 `mybatis-capture.log` 后 `共 6 条`，行是「色条 + `#序号 时间 耗时 (影响行数)` + SQL」。
   已验 2026-11-26：`#1 … 21:00:01.001 5`、`#6 … 21:00:06.700 280 (3)`（耗时与影响行数已解析，D7 修复可见）。
3. 筛选：点「搜索」展开搜索行，输入 `orders` → `共 2 条`，只剩两条含 `orders` 的语句；清空后恢复 `共 6 条`。
   已验 2026-11-26（D1 修复）。
4. SQL 类型多选：`全部` 按钮弹层勾 SELECT/INSERT/UPDATE/DELETE/CREATE/DROP + 「只看慢查询」+ 全选/全不选。
   待验（弹层交互本轮只确认按钮与文案在位）。
5. 复制 SQL：点「复制 SQL」，剪贴板读回 6 条语句，**每条都以 `;` 结尾**。已验 2026-11-26。
6. 暂停/恢复：点「暂停」→ 按钮变「继续」并高亮；点「继续」恢复。已验 2026-11-26。
7. 缓冲上限：`logs.pageSize` 作为条数上限，状态行显示 `共 N 条` / `已截断到上限 N`。待验（需改设置，设置页见 D5）。
8. 行交互：单击选中、右键菜单（复制 SQL / 复制时间戳 / 导出可见行集）、双击送工作台。待验。
9. 页签：按原版复刻**五**个页签 `SQL 日志 / 日志 → SQL / SQL → Java / SQL 历史 / SQL 预览`（自绘 tab strip，
   切换只切 DOM，日志页的行集/筛选/滚动不丢；第 5 页签常驻、无关闭按钮，与原版 Registry 开关的差异见 L23 注册文档）。
   已验 2026-11-26：五页签都在、默认 SQL 日志；切走再切回 `共 6 条` 不变。右栏只剩**一个**插件图标（`contributes 1 × views`）。
   - 日志 → SQL：已验——`还原后的 SQL` 为 `UPDATE orders SET status = 'SHIPPED' …`，`原始 SQL（? 占位）` 与
     `参数（按顺序）` 并列，按钮 `复制 SQL` / `发送到工作台`。
   - SQL → Java：已验——输入 `SELECT id, name FROM users WHERE id = 1` + 实体 `User` 后点「转换」，
     得到 `LambdaQueryWrapper<User> wrapper = new LambdaQueryWrapper<>(); .select(…).eq(…)`，`复制代码` 由禁用变可用。
     （生成文本的换行位置有点怪：`wrapper .select(…)` 分两行，属排版小瑕疵。）
   - SQL 历史：已验——搜 `users` 命中 4 行（`SELECT id, name, email FROM users WHERE id = 42..45`），
     每行带 `[来源: -]`（解析器不给源码位置，如实留空）；搜索范围是本会话已捕获的缓冲区，不是持久化历史（见 `docs/LIMITS.md`）。
   - 日志 → SQL：选中行（无选中取最后一条）→ 原始 SQL + 参数 → 还原后 SQL，可复制 / 发送到工作台。
   - SQL → Java：输入 SQL（+ 实体类名）→ 复用 `sqlv_reverse_sql` 生成代码；unresolved 只给原因（实体缺失时 `gen.java.entity_required`）。
   - SQL 历史：搜索范围是**本会话已捕获的日志缓冲区**（不是持久化历史，见 `docs/LIMITS.md`）；无来源文件列（解析器不给源码位置）。
