## 4 面板验收

### 4.1 SQL 日志（`sqlv-logs`）

1. 空态：打开面板，显示「尚未捕获到 SQL 语句。」，分页 `0-0 / 0`。已验。
2. 数据行：加载 `mybatis-capture.log` 后显示 6 行，列名与内容正确。已验。
3. 筛选：筛选框输入 `orders`，只剩含该词的 SQL 行；清空恢复 6 行。待验。
4. 类别下拉：切「慢查询」「错误」等，行集按类别变化。待验。
5. 复制 SQL：点「复制 SQL」，剪贴板内容为可执行 SQL。待验。
6. 暂停/恢复：暂停后新数据不滚动，恢复即刷新。待验。
7. 分页：把 `logs.pageSize` 调到 2，面板显示 2 行并可翻页。待验。
8. 行交互：单击行选中、双击/Enter 行为符合第 5 节导航预期。待验。

### 4.2 SQL 工作台（`sqlv-workbench`）

1. 空态：显示「暂无可预览内容。」，方言 `MySQL`。已验。
2. 带 SQL：右键 `check.sql` 打开工作台，SQL/参数区出现该语句；导出/复制可用。待验。
3. 方言切换：改为 `PostgreSQL`，展示字段/格式化随方言变化。待验。
