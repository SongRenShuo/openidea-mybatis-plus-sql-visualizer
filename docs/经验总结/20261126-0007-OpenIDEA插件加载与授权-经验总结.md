# OpenIDEA 插件加载与权限：link 之后为什么命令消失

> 归属：跨任务复用（插件安装/升级/权限变更）。证据仓：`openidea-mybatis-plus-sql-visualizer`。
> 相关：[[20261126-0007-OpenIDEA清单与界面集成-经验总结]]

## 现象

`openidea-plugin link .` 返回成功、`openidea-plugin links` 也能回读路径，但在 IDE 的
Find Action 里搜插件命令得到「未找到任何内容」——不是新命令缺失，是**整个插件没被加载**。

## 根因

1. 应用把「用户批准的能力集合」持久化在
   `%APPDATA%\ai.l0ng.openidea\plugins\grants.json`。本插件条目原先只批了 `project.read`。
2. 新 manifest 把 `events` 提升为 **required**。required 集合与已批准集合不一致时，应用不弹窗、
   不报错，直接不加载插件（日志里也没有显眼的 ERROR 行）。
3. 窗口「关闭」只是收起应用，进程仍在（`Get-Process openidea` 的 `StartTime` 不变）；
   此时改 `grants.json` 不会重新读取。

## 对策（验证过的顺序）

1. 先确认进程与启动时间：`Get-Process openidea | Select Id,StartTime`。
2. 真正退出（窗口关闭不够）：主菜单「退出」失效时用 `Stop-Process -Id <pid> -Force`，
   确认进程消失。
3. **先备份** `grants.json`（例：`grants.json.bak-before-<plugin>`），在插件条目里把新 required
   能力加入 `granted`，optional 能力按需一并加入。
4. 重启应用后，Find Action 立即能列出命令；`views` 的 tool window 按钮也会出现。
5. 升级说明里要写一条：**新增 required 能力会让已 link 的插件静默不加载，需要重新批准**。

## 判据

- 只看 `link`/`links` 成功**不能**证明插件在跑；必须在 IDE 里搜命令或看视图按钮。
- `openidea-plugin check` 通过只证明包合法，不证明授权覆盖了 required 集合。

## 附带结论

- 视图（tool window）随插件加载即注册，不需要命令激活。
- `javaAgents` 派生 `java.agent` 属于 optional/high，缺它不会阻止加载，只影响 agent 注入。
