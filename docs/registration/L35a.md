# L35a 注册申请：SQL 预览入口（命令 / 快捷键 / gutter 按钮）

本车道补「SQL 预览」的**入口与宿主侧**：`preview-sql` 命令、mapper 语句行的
gutter 预览按钮、以及两者共用的预览页签落点。UI 版式不在本车道。

原版（IntelliJ 仓）的入口是三个：mapper gutter 预览图标、右键菜单、
`Alt+Shift+Q`（`plugin.xml:68/84`、`:608`）。原版点击后弹 `SqlPreviewDialog`
模态框；OpenIDEA 没有插件可用的模态对话框 API，因此本端口**统一落到侧栏
`sqlv-logs` 工具窗的第 5 个页签**（`sqlv-logs#preview`），渲染链与原版一致，
差别只有外壳。

`plugin.toml` 由主控独占，本车道未改；以下片段由主控在 `chore: 注册汇总` 时一次性应用。

## 1 `plugin.toml` — 新命令

放在现有 `[[contributes.commands]]` 区块内（`open-workbench` 之后即可）：

```toml
[[contributes.commands]]
id = "preview-sql"
title = "MyBatis SQL: Preview SQL"
category = "MyBatis SQL Visualizer"
```

## 2 `plugin.toml` — 新快捷键

`Alt+Shift+Q` 与原版一致。SDK 字段为 `command` / `key`（可选 `mac`）：

```toml
[[contributes.keymaps]]
command = "preview-sql"
key = "Alt+Shift+Q"
```

> 原版该快捷键打开的是 SQL 日志工具窗里的**独立预览页签**并用剪贴板里「像 SQL
> 的文本」预填；本端口的无参形式读**当前编辑器**（选区优先，否则整篇），不读剪贴板
> ——见 §6 差异表。

## 3 `plugin.toml` — 新 provider kind

`gutter-actions` 需要 API 1.4+（本仓 `engines.openidea = "^1.15"`，满足）。
语言只声明 `xml`；非 mapper 文档由代码再筛一次。

```toml
# Mapper 语句行的预览按钮；点击运行 preview-sql（L35a）。
[[contributes.providers]]
kinds = ["gutter-actions"]
languages = ["xml"]
```

## 4 `plugin.toml` — 图标声明

gutter 按钮的 `icon` 返回包内路径 `icons/sqlGutter.svg`（原版同款预览图标）。
gutter 动作的图标只认「图标名 / 别名 / **已声明的** marker SVG 路径」，所以要把
这个既有文件补进 `markerIcons`，安装时才会被打包与校验：

```toml
[[contributes.markerIcons]]
id = "sql-preview"
icon = "icons/sqlGutter.svg"
```

说明：

- 该文件已在仓内（16×16，`circle`/`path`/`line` + `fill`/`stroke`，无脚本/外链），
  能过宿主 SVG 清洗；没有单独的 dark 变体（`iconDark` 可省）。
- **若主控不想新增 markerIcon**：把 `src/providers/gutter.rs` 的
  `pub const ICON` 改成 `"icons/marker-statement.svg"`（已声明，`id = "statement"`）
  即可零注册生效，代价是按钮图标变成语句线标记而不是预览放大镜。

## 5 `plugin.toml` — 能力

`editor.read` 加到 **optional**（与 `clipboard` / `process:java` / `net:127.0.0.1` 同级）：

```toml
optional = ["clipboard", "process:java", "net:127.0.0.1", "editor.read"]
```

为什么需要：无参形式（快捷键 / Find Action）要读当前编辑器的选区或全文。**降级**：
用户拒绝时命令仍可用入参形式（`<path>#<id>`、`<mapper.xml>`、`@<path>`、行内 SQL），
无参形式报 `preview.error.editor_unreadable` 并在 Output 指明改传参数。

## 6 `src/lib.rs` — 可选导出

`gutter-actions` 走 `language_features` 接口，需要把该导出加进宏：

```diff
 register_plugin!(
     Main,
     views,
     indexing,
     providers,
     injections,
     inlay_hints,
     diagnostics,
+    language_features,
     mcp
 );
```

（命令分发那一行本车道已自行加到 `src/lib.rs` 的 `run_command` 里。）

## 9 应用后的读数（主控自检）

- `[[contributes.commands]]` 计数 **+1**（`preview-sql`）。
- `[[contributes.keymaps]]` 从 0 → 1（`Alt+Shift+Q`）。
- `[[contributes.providers]]` 计数 **+1**（`kinds = ["gutter-actions"]`, `languages = ["xml"]`）。
- `[[contributes.markerIcons]]` 从 3 → 4（`sql-preview`）。
- `[capabilities] optional` 从 3 → 4（新增 `editor.read`）。
- `openidea-plugin check .` 应仍为 `ok`；若报 `gutter-actions` 未声明，说明 §3 没应用。

## 10 与原版的行为差异（必须写进文档）

| 项 | 原版 IntelliJ | 本端口 | 原因 |
| --- | --- | --- | --- |
| 预览外壳 | `SqlPreviewDialog` 模态框 | `sqlv-logs` 第 5 页签 `#preview` | OpenIDEA 无插件模态对话框 API |
| gutter 点击 | 弹框预览该语句 | 运行 `preview-sql <path>#<id>`，切到预览页签 | 同上 |
| `Alt+Shift+Q` | 打开独立预览页签，剪贴板疑似 SQL 时预填 | 打开预览页签，无参时读**当前编辑器**（选区优先，否则整篇） | 本车道按任务口径实现；剪贴板预填未做（`clipboard.read` 非必需能力，且无参读编辑器对 IDE 内使用更直接） |
| 右键菜单 | 有 | 本车道未加；`plugin.toml` 的 `editor.context` 菜单可由主控按需补 | 菜单注册属主控单点文件 |
| 多语句 mapper | 预览指定语句 | 裸路径渲染全部语句，页签显示第一条，Output 摘要给出总数 | 预览页签模型只承载一条语句 |
| Wrapper 链 | 引擎渲染 | 文本模式（按 SQL 文本原样预览） | 本端口没有 Wrapper 命令/引擎入口（`sidecar` 只有生命周期与协议，无调用方），沿用「无引擎降级为文本」 |
| 预览结果落点 | 弹框 + 工具窗 | 工作台模型 → `selectTab=preview` → `reveal_view("sqlv-logs")` | 与 `open-workbench` 同一条推送协议，未新增第二种 `post_view_message` |
