| 13 | `preview-statement` | `id: string`（取自 `model.statements`） | `model.*` 换成该语句的渲染结果、`statement`/`source` 跟随、`replaceInput=true`；参数/方言/显示开关不动。未知 id 或无 mapper 文档时只改 `status` | —（拒绝写 status） | SQL 页签上方「目标语句」下拉切换 | `"statement"` |

状态往返：两个开关是**页面状态 + 宿主记忆**，不进 settings。页面切换时先本地生效，
再 `post({op:"preview-display", …})`；宿主存进 `PreviewStore.display`，此后每次
`state` 推送都带 `display: {keywordWrap, vertical}`，页面在 `applyTab` 里读回。
所以切走页签再回来、甚至整页重挂，开关值都保持。缺字段（旧宿主 / 首次推送）时页面保留现值，
不会被重置。

## 4 两个纯展示函数的边界

- `wrapKeywords(sql)`：在 `PV_WRAP_KEYWORDS` 里的关键字前断行。清单：`SELECT`、`FROM`、
  `WHERE`、`GROUP BY`、`ORDER BY`、`HAVING`、`LIMIT`、`OFFSET`、`JOIN`（含 `LEFT/RIGHT/FULL/INNER/CROSS`
  及 `* OUTER JOIN` 组合）、`ON`、`AND`、`OR`、`UNION`（含 `UNION ALL`）、`INSERT INTO`/`INSERT`、
  `UPDATE`、`DELETE FROM`/`DELETE`、`VALUES`、`SET`、`WITH`。只插入换行与去掉行首缩进，
  不增删改任何 token；字符串字面量、引号标识符、`--` 行注释与 `/* */` 块注释整段跳过。
- `verticalItems(sql)`：只在**括号深度 0** 的逗号后换行，函数实参 / `IN (…)` / 子查询内的逗号不动。
- `shapeForDisplay(sql, {keywordWrap, vertical})`：先竖排再换行；两个都关时原样返回。
- 三者都不碰 `model.sql`：复制 / 导出 / 重绑定参数走的仍是宿主那份原文。
