## 包内新文件 `settings.schema.json`

`[contributes.settings]` 只接受 schema 文件（见 `MANIFEST_REF` §settings）。主控需新增该文件：

```json
{
  "properties": {
    "nav.enabled": {
      "type": "boolean",
      "title": "Mapper navigation (Go to Declaration, gutter markers)",
      "default": false
    },
    "injections.enabled": {
      "type": "boolean",
      "title": "SQL highlighting inside mapper XML",
      "default": false
    },
    "sql.dialect": {
      "type": "string",
      "title": "SQL dialect for quote checks",
      "enum": ["", "mysql", "mariadb", "postgres", "oracle", "sqlserver"],
      "default": ""
    }
  }
}
```

- 键名与代码一致：`nav.enabled`、`injections.enabled`、`sql.dialect`（`host::setting*` 读取）。
- 若 IDE 的设置页拒绝带点的属性名，改名为 `navEnabled` / `injectionsEnabled` 时需同步改
  `src/providers/mod.rs`、`nav.rs`、`inject.rs` 的常量（三处），并重跑
  `cargo test providers`。这是唯一需要主控确认的注册风险点。

## locales 键

诊断给的是稳定 `code` + 英文 message，建议 L5 给 code 补文案（message 由引擎侧替换或直接本地化）：

```json
"diag.unknown_column": { "en": "Unknown column", "zh": "未知列" },
"diag.quote_style": { "en": "Quote style does not match the dialect", "zh": "引号风格与方言不符" }
```

行标记 tooltip 与 inlay tooltip 目前是英文短句（`MyBatis: go to sql fragment …`、`columns of …`）。
如果 L5 的 `i18n.rs` 要接管，需要在 `providers/nav.rs`、`providers/inlay.rs` 各换一处 `format!`。

## 行为与预算（供复核）

- 所有 provider 只读当前 `Document.text`，单遍扫描、无 IO、无 host 调用（除读设置），
  结果只由文本决定；文档变更即重算，不做跨文档缓存。
- `DocumentIndexer` 走后台批次（SDK 限 2 MiB/文件、16 文件/批），不占编辑路径预算。
- 跨文件跳转来自索引键（T3-1）：XML `stmt:`/`mapper:`/`frag:`/`rm:`/`type:` 与 Java
  `java:#`/`mapper:`/`type:` 同名即匹配，多模块与 MPJ 不依赖文件系统布局。
- `providers::definition` 只解析同文档目标（include refid、resultMap/extends、`@ResultMap`→
  `@Results(id)`）；跨文件由索引负责，这是「预算内可确定性回答」的边界。
- inlay 与「未知列」共用 `providers::set_column_lookup`：L8 拿到真实 schema 后调用即可点亮；
  未设置时两处都不出结果（不误报）。

## 集成点

`src/providers/mod.rs` 公开：

```rust
pub fn set_column_lookup(lookup: Option<fn(&str) -> Option<Vec<String>>);
```

L8（schema 缓存）在首次加载表结构后调用；DDL 变化时重新设置即可。表名按语句中写法传入
（未加引号），实现方自行决定大小写规范化（L6 内部比较不区分大小写）。
