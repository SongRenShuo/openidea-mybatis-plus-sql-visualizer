## src/lib.rs（dispatch 片段）

```rust
match id {
    commands::render_xml::ID => commands::render_xml::run_with_arg(ctx, arg),
    commands::check_sql::ID => commands::check_sql::run(ctx, arg),
    commands::perf_advice::ID => commands::perf_advice::run(ctx, arg),
    commands::generate_crud::ID => commands::generate_crud::run(ctx, arg),
    commands::rollback_plan::ID => commands::rollback_plan::run(ctx, arg),
    commands::render_log::ID => commands::render_log::run(ctx, arg),
    _ => Err(Error::NotFound(format!("command {id}"))),
}
```

- `render_xml` 保留了一个 `run(ctx)` 包装（等价于 `run_with_arg(ctx, None)`），只为让
  现有 `src/lib.rs` 编译；接线时把分支换成 `run_with_arg(ctx, arg)`。
- **必须同步改 `src/lib.rs` 的测试 `routes_render_xml_to_its_command`**：它现在不传 arg，
  断言的是旧 P0 固定 SQL（`SELECT id, name, created_at`）。改成先 `MockHost::add_file`
  写一个 mapper，再 `run_command(ID, ctx, Some("<path>#<ns>.<id>"))` 并断言真实 SQL，
  否则该测试会红（命令行为已不是固定样例）。
- `commands::CHANNEL` 是唯一的 Output 频道常量；`commands::render_xml::CHANNEL` 是对它的
  再导出，旧引用不需要改。

## 行为与预算（供复核）

- 输出统一 `output_clear` → `output_append` → `output_reveal`，单次最多 200 KiB；
  超限按 UTF-8 字符边界截断并追加 `cmd.output.truncated`。
- `render-log` 命令预算 5 s：测试覆盖 100000 行日志（50000 条 SQL），只格式化前 N 条。
- 所有错误路径都写可读的 `-- error [key]: detail` 并返回 `Error::Failed`；
  `rollback-plan` 的拒绝（无主键 / WHERE 未覆盖主键）是设计内结果，写
  `-- refused: <key>` 且**不输出反向 SQL**，命令本身返回 `Ok`。
- `render-xml` 省略 statement 时渲染文件内全部语句；`unresolved` 只输出原因，不输出 SQL。
- 单元测试随模块（`cargo test commands` 可覆盖），`tests/l11_commands.rs` 另有 7 个
  mock 端到端用例（因 `src/lib.rs` 的 `mod commands;` 是私有的，测试文件用 `#[path]`
  把同一份 `core`/`commands` 源码编进集成测试 crate）。
