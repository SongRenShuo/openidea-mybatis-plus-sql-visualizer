读取被拒时（`NotAllowedError`）同样置灰并说明。

## 页面 → 宿主的 op（新增）

| op | 载荷 | 行为 |
| --- | --- | --- |
| `capture-start` | — | 转发 `commands::capture_start::run(ctx, None)`；命令自己写 Output（连接/已连接/失败原因），随后回推状态。**不**把命令错误再抛给平台（避免双报）。 |
| `capture-stop` | — | 转发 `commands::capture_stop::run(ctx, None)`，同上。 |
| `follow` | `follow: bool` | 页面在滚离/滚回底部时上报翻转；宿主记镜像，`status.follow` 用于状态栏。 |
| `scroll-end` | — | 恢复跟随（`follow = true`）并回推 + 刷新视图。 |
| `sort` | `sort: "time"\|"duration"` | 切换显示顺序并回推。非法值忽略。 |
| `toggle-group` | `line`、`kind: "dedupe"\|"group"` | 翻转该行所属组的展开态并回推。行没有对应组键时 no-op（页面也只在这时才可点）。 |
| `settings` | — | `host::notify` + Output 指路（平台没有打开设置页的 API）。 |
| `help` | — | Output 打印一屏快捷键/交互速查。 |

| `preview-rollback` | — | 回滚入口的设计性拒绝：工作台没有表/主键元数据，只回状态说明，不猜表。 |

## 宿主 → 页面的状态（新增字段）

```
{
  ...,
  sort: "time" | "duration",
  rows: [{ ..., dedupe_key, n_plus_one_key, expanded }],
  filter: { ..., blocked: ["class#method", ...] },   // 由数量改为键列表
  counts: { ..., blocked: <number> },                // 数量仍在此
  status: { ..., follow: bool }
}
```

- `filter.blocked` 由数字改为**键数组**（L26 的屏蔽弹层要列出具体方法）；`counts.blocked` 仍是数量，
  既有断言与页面的计数胶囊不受影响。
- 行上的 `dedupe_key` / `n_plus_one_key` 是徽章可点的前提（空串 = 该组不存在/未折叠）；
  `expanded` 表示该行属于某个展开中的组。

## 语义

- **两个暂停概念分离**：`status.paused`（刷新暂停，既有）与 `status.follow`（跟随暂停，新）。
  页面在 `scrollTop + clientHeight >= scrollHeight - 4` 处判「在底部」；滚离底部 → `follow=false`
  （上报宿主），滚回底部或点「滚动到底」→ `follow=true`。列表重建时的滚动事件被页面吞掉一次
  （`suppressScroll`），不会把一次重渲染误判成用户滚离。
- **排序**：`duration` 按耗时降序（无耗时的行置末，稳定排序保留同值行的捕获顺序），作用在
  筛选之后的可见集合；缓冲上限取排序结果的前 `cap` 行（`time` 时即最近 `cap` 行，`duration`
  时即最慢 `cap` 行）。
- **同结构展开**：组键为 `d:<去重键>`（⨉N 徽章）或 `n:<N+1 模板>`（×N 徽章）。展开时宿主把该组
  的每条 occurrence 连续下发：首条保留组计数（徽章变为折叠入口），其余为成员行（`dedupe_count`
  / `group_count` 为 1），页面按「组键与上一行相同」识别并缩进，逐条显示自己的时间与耗时。
  两个维度都展开时按两组行号的并集只下发一次（去重开启时同组多行只发一遍）。
- **参数回填**：值渲染规则——`null`（不分大小写）→ `NULL`；十进制数（可选正负号、至多一个小数点、
  至少一位数字）与 `true`/`false` 裸写；其余按字符串加单引号、内部 `'` 双写。随后交给
  `core::log::restore_rendered` 的占位符扫描器按序替换（与日志还原同一个扫描器，不会二次加引号）。
  SQL 里没有 `?` 时回 `params_no_placeholder` 状态，不改 SQL。
- **导出**（L27 核对项）：导出体是 `model.sql` 经当前方言格式化后的「可执行 SQL」；参数回填之后
  导出的就是回填后的值（单测 `exporting_after_a_rebind_carries_the_bound_values` 钉住）。
- **显示模式**（L27 核对项）：`formatted` 由宿主按**配置方言**现算（`preview_tab` 里
  `formatted_sql(&dialect_name)`），页面只切换渲染源；既有行为已满足「随方言变化」，未改。

## 做不到 / 已知边界

- **设置入口**：平台没有「打开设置页」的 API（SDK `host::` 面里没有对应函数），所以按钮走
  `notify` + Output 指路，不做点了没反应的按钮。
- **工作台回滚**：`core::gen::rollback` 需要表描述（表名、列、主键）；工作台的模型只有 SQL 文本
  与参数，没有表/主键元数据，无法可靠构造 `TableSpec`。因此「生成回滚」按钮**常驻禁用**并把原因
  写在 tooltip（`view.workbench.rollback.note`），宿主 op 也只回拒绝状态——不猜表、不猜主键。
  需要回滚时用既有的 `rollback-plan` 命令并给出表描述。
- **跟随是页面本地状态 + 宿主镜像**：页面拥有 `follow`，只在翻转时上报；宿主不主动改它
  （`scroll-end` 除外）。
- **展开态是会话级**：`expanded` 集合在 `clear()` 时清空，不持久化；组键是内容键，`set_log_text`
  换文本后仍按内容匹配。
- 剪贴板导入只填参数表、**不自动重绑定**（按需求），由用户再点「重绑定」。
