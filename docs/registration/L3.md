## 备注（主控合并时须知）

- 公开 API：
  - `core::perf::{analyze(sql, dialect) -> Vec<Finding>, score(sql) -> Complexity,
    index_advice(sql, indexes) -> Vec<IndexAdvice>}`；
  - `core::r#gen::{crud, crud_batch, to_mybatis_plus_java, rollback_plan, TableSpec,
    ColumnSpec, GenError}`。
- 21 条 `CANONICAL_RULE_IDS` 与 IntelliJ 仓 `PerfRulesBatch1..4` 的 `ruleId` 一一对应，
  名字与 messageKey 均照抄；后续 `cases.jsonl` 对拍可按该集合过滤，扩展规则
  （`EXTENSION_RULE_IDS`，5 条）不属于对拍基线。
- 所有 Finding / 生成结果均 `serde` 可序列化；`Severity` / `ComplexityLevel` /
  `Confidence` 序列化为小写。
- `rollback_plan(sql, table, dialect)` 的 `dialect` 为第三参（模块文档已注明）；无主键返回
  `GenError::NoPrimaryKey`。
- 本车道不新增依赖；`src/core/perf/dialect.rs` 是**本车道内部**的方言引号表，不与 L2 的
  `core::dialect` 合并（L2 交付后如需统一，由主控裁决）。
