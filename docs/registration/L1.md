## 交付 API（其他车道按此调用）

```rust
// core::xml
pub enum Confidence { Exact, Partial, Unresolved }        // serde: snake_case
pub struct Note { pub message_key: String, pub detail: String }
pub struct RenderOutput {
    pub sql: String,            // 用 ? 占位
    pub params: Vec<serde_json::Value>,  // 按出现顺序
    pub confidence: Confidence,
    pub notes: Vec<Note>,
    pub message_keys: Vec<String>,
}
pub fn render_statement(xml: &str, statement_id: &str, params: &Value) -> RenderOutput;
pub struct MapperSet;   // 多文档 / 跨命名空间 include
impl MapperSet {
    pub fn load(docs: &[(&str, &str)]) -> (MapperSet, Vec<LoadIssue>);
    pub fn render(&self, qualified_id: &str, params: &Value) -> RenderOutput;
    pub fn statement_ids(&self) -> Vec<String>;
}

// core::annotation
pub enum AnnotationKind { Select, Insert, Update, Delete }
pub struct AnnotatedStatement { kind, sql, line, annotation_start, annotation_end,
                                 method_name, method_line, method_start, is_script }
pub fn parse_annotations(java_text: &str) -> Vec<AnnotatedStatement>;
pub fn render_annotated(stmt: &AnnotatedStatement, params: &Value) -> RenderOutput;

// core::ibatis
pub fn render(xml: &str, statement_id: &str, params: &Value) -> RenderOutput;
pub fn parse(xml: &str) -> Result<IbatisModel, ParseError>;   // 供 UI 列语句/参数图
```

契约：`unresolved` 时 `sql` 必为空串；`partial` 表示产物可能缺段（缺失 include
占位、`${ew...}` 无值、foreach 集合为 null、未知 iBatis 标签等）；`exact` 表示按
受限规则完整渲染。所有 key 点号小写、由 `src/i18n.rs` 映射文案。

## 给后续车道的注意事项

- `render_statement` 只解析单文件；跨命名空间 include 用 `MapperSet`。
- `params` 是 `serde_json::Value`：顶层对象的键即 mapper 变量；标量参数会同时绑定
  `_parameter` 与 `value`。
- 空白口径：相邻文本段以一个空格连接、首尾裁剪，段内空白原样保留（与主仓一致，
  不做美化重排）；`<trim>` 内部按「会拼成词才补空格」的规则紧凑拼接。
- iBatis 侧 `open`/`prepend`/`conjunction`/`close` 逐字拼接、不补空格，与 MyBatis 3 链相反。
