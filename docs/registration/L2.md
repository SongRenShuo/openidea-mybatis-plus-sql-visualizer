# L2 注册申请

车道 L2（feat/dialect-params）交付纯逻辑引擎的方言表 / 参数还原 / 格式化三块，
均为 `src/core/` 下的库 API，不新增命令、能力、视图或 MCP 工具。

## plugin.toml

无。L2 不注册命令 / provider / 视图 / MCP 工具 / javaAgent。

## capabilities

无新增。纯逻辑层不触碰任何 host 能力。

## src/lib.rs

无。`src/core/mod.rs` 已声明 `dialect` / `params` / `format` 三个模块（基线已铺），
本车道只在目录内新增文件（`core/dialect/{keywords,tests}.rs`、`core/params/tests.rs`），
未改 `src/core/mod.rs` 与 `src/lib.rs`。

## Cargo.toml / Cargo.lock

无新增依赖。仅使用已在基线 `Cargo.toml` 声明的 `serde` / `serde_json`
（Apache-2.0/MIT，理由：参数值与能力结构的序列化）。

> 注：基线 `Cargo.lock` 的包依赖清单当时未包含 `serde` / `serde_json`（Cargo.toml 已声明），
> 本地 `cargo test` 会自动补上这两行。按车道纪律未提交 `Cargo.lock`，交主控在 `chore: 注册汇总`
> 或合并时统一处理。

## 跨车道公开 API（供 L5/L8/L9 依赖）

```rust
// core::dialect
pub fn all() -> &'static [Dialect];
pub fn by_name(name: &str) -> Option<&'static Dialect>;
pub struct Dialect { pub name: &'static str, pub capabilities: Capabilities, /* reserved_words via method */ }
impl Dialect {
    pub fn reserved_words(&self) -> &'static [&'static str];
    pub fn render_limit(&self, limit: u64, offset: Option<u64>) -> String;
    pub fn quote_identifier(&self, ident: &str) -> String;
    pub fn quote_if_keyword(&self, ident: &str) -> String;
    pub fn quote_if_needed(&self, ident: &str, source: IdentifierCaseSource) -> String;
    pub fn render_upsert(&self, conflict_key: &str, update_columns: &[&str]) -> Option<String>;
    pub fn render_upsert_statement(&self, table: &str, columns: &[&str], conflict_key: &str) -> Option<String>;
    pub fn render_identity_wrapper(&self, table: &str, sql: &str) -> Option<String>;
}
pub struct Capabilities { /* pagination, quote_open/close, identifier_quotes, identifier_folding,
                             supports_delete_limit, limit_requires_order_by, upsert, identity_wrap,
                             supports_boolean_literal, supports_ansi_date_literal, keyword_case */ }
pub enum IdentifierFolding { Upper, Lower, None }
pub enum IdentifierCaseSource { Catalog, Entity }

// core::params
pub fn bind(sql: &str, params: &[serde_json::Value], dialect: &Dialect) -> BoundSql;
pub struct BoundSql { pub sql: String, pub params: Vec<SqlLiteral>, pub confidence: Confidence,
                      pub warnings: Vec<String>, pub message_keys: Vec<String> }
pub enum Confidence { Exact, Partial, Unresolved }

// core::format
pub fn format(sql: &str, dialect: &Dialect) -> String;
```
