## 1. 三个新键

| 键 | 页面 / 分组 | 类型 | 默认 | 标题（en → zh） | 消费者落点 |
| --- | --- | --- | --- | --- | --- |
| `logs.displayMode` | SQL Log / Log | enum `single` \| `multi` \| `keyword_wrap` | `keyword_wrap` | `SQL display mode` → `SQL 显示模式` | `src/views/log_panel.rs`：`display_mode()` 归一化、`sql_line_limit()` 把模式解析成行数；`build_state()` 推送 `displayMode` 与 `sqlMaxLines`（`null` = 不折叠）。`web/log-panel.html`：`foldSql()` 按 `sqlLineLimit` 折叠——`single` 1 行、`multi` 全部行、`keyword_wrap` 3 行 + `… (+N)`。 |
| `log.showDuration` | SQL Log / Log | boolean | `true` | `Show execution duration` → `显示执行耗时` | `build_state()` 推送 `showDuration`；`web/log-panel.html` 的行头只在为真时追加耗时段，慢查询着色（`.hot`）随该段一起消失，其余行头不变、不报错。 |
| `render.formatOnPreview` | SQL Preview / Rendering | boolean | `true` | `Format restored SQL on preview` → `预览时格式化还原 SQL` | `src/views/workbench.rs`：`format_handoff_sql()`，在页面回报「已切到预览页签」时对**交接过来**的语句走 `core::format::format`；`false` 时逐字节保留原文。 |

三个键都由 `settings::get_*` 在每次推送/交接时读取，**不需要重启 IDE**（`needs_restart: false`），
`settings` 模块的 `schema_json_matches_the_code_definitions` 保证 schema 与 `DEFINITIONS` 的
类型/标题/分组/默认值/枚举逐项一致。

### 1.1 `render.formatOnPreview` 的时序

原版的语义是「格式化**还原** SQL」，即由命令或日志行交接进来的语句，不含用户自己敲的文本。
本端口的交接链是：

1. `open-workbench` / `preview-sql` / 日志行的「打开预览」（`open-line`、`history-open`）
   → `workbench::set_model()` + `request_input_replace()` + `request_tab()`；
2. 页面收到 `selectTab: "preview"` 后切页签并回报 `{op:"tab"}`；
3. `log_panel` 的 `tab` 分支调 `workbench::format_handoff_sql()`：设置开 → 按配置方言格式化
   `model.sql`，并把下一次推送标成「重写输入框」，让上方输入区与下方预览一致；设置关 →
   原样保留，字节不动。

`request_input_replace()` 同时打一个一次性「handoff」标记，只有命令交接会置位，所以页面里
手动「解析/还原」（`preview-render`）走的是原样渲染——那一步的逐字节契约由既有测试钉住，
不在本设置的作用域内。

## 3. 差异表：原版有、本版不加的两个键

| 原版设置 | 原版语义 | 不加的原因 |
| --- | --- | --- |
| 数据源角标完整上下文 | 行头的数据源角标显示完整连接上下文（连接名 + 库名） | 本端口拿不到**连接名**：捕获链只给语句，不携带连接/数据源标识。现有角标（L32）只写设置里配置的引擎名，行里自带库名时才追加，从不猜连接。加这个键没有任何可观测差异，属死设置。 |
| 执行耗时前缀 | 在聚合/导出文本里给语句加 `Time:` 形式的前缀 | 原版的耗时前缀来自对 `Time:` 行的解析；本端口的 `duration_ms` 来自 `==>  Total:` / 耗时字段，不产出 `Time:` 前缀文本，导出也没有这一列。加键只能造假实现。 |

（原版另有表名映射、快捷键、MCP、关于四页设置；本版无对应功能，此前已决定不造空页，本次不变。）
