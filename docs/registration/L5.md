# L5 注册申请（界面车道 T2-1~T2-5）

本车道交付两个面板（SQL 日志、预览工作台）、设置 schema、双语表与两套图标。
以下片段由主控在 `chore: 注册汇总` 一次性落到 `plugin.toml` / `src/lib.rs`。

## plugin.toml — 视图

```toml
[[contributes.views]]
id = "sqlv-logs"
title = "SQL Logs"
icon = "icons/marker-statement.svg"
location = "bottom"

[[contributes.views]]
id = "sqlv-workbench"
title = "SQL Workbench"
icon = "icons/mapper-xml.svg"
location = "right"
web = "web/workbench.html"
```

- `sqlv-logs` 的正文由代码渲染（`Body::Html`），分页由 `Viewport` 驱动；
  宿主调用 `render("sqlv-logs", viewport)`，按钮/页面消息走 `handle`。
- `sqlv-workbench` 是包内页面；`web/` 目录整体随包签名，页面内只用
  `openidea.postMessage/onMessage`，无外链、无本地存储、无网络。
  插件用 `host::post_view_message("sqlv-workbench", …)` 下发 `{op:"load", model, labels}`。
- 两个视图都无需 `when`；导航/注入开关在设置里，不控制视图可见性。

## plugin.toml — 设置

```toml
[contributes.settings]
schema = "settings.schema.json"
```

`settings.schema.json` 40 个字段分五组（Dialect / Log / Rendering / Navigation / Engine），
键名与 L6/L8 注册片段一致：

| 组 | 键 |
| --- | --- |
| Dialect | `dialect.mode`、`dialect.default`、`dialect.detectFromUrl`、`dialect.autoDetectFromMappers`、`dialect.quoteIdentifiers`、`dialect.keywordCase` |
| Log | `log.prefix`、`log.slowThresholdMs`、`log.nPlusOneThreshold`、`log.dedupe`、`log.dedupeWindowMs`、`log.ignoreParamsInDedupe`、`log.maxSqlLength`、`log.refreshIntervalMs`、`log.timestampOffsetMinutes`、`log.showRawLine` |
| Rendering | `render.paramsSeparator`、`render.sqlCase`、`render.dateFormat`、`render.showConfidence`、`render.formatSql`、`render.indentWidth`、`render.truncateSql`、`render.exportFormat` |
| Navigation | `nav.enabled`、`nav.showLineMarkers`、`injections.enabled`、`injections.language`、`inlay.enabled`、`inlay.insertColumns`、`diagnostics.enabled`、`diagnostics.unknownColumn`、`diagnostics.dialectQuotes` |
| Engine | `engine.downloadUrl`、`engine.autoDownload`、`engine.degradePolicy`、`engine.startupTimeoutMs`、`engine.requestTimeoutMs`、`engine.javaPath`、`engine.maxRestarts` |

需重开文件/IDE 才生效的键（schema 无法表达，写在 `src/settings.rs` 的 `needs_restart`）：
`nav.enabled`、`nav.showLineMarkers`、`injections.enabled`、`injections.language`、
`inlay.enabled`、`diagnostics.enabled`。其余字段每次读取即生效。

默认值要点：导航与注入全关（`nav.enabled=false`、`injections.enabled=false`、
`inlay.enabled=false`、`diagnostics.enabled=false`）；慢阈值 1000 ms；N+1 阈值 5；
刷新间隔 250 ms；去重开启。

## capabilities

```toml
optional = ["clipboard"]
```

- `clipboard`：工作台复制/导出按钮与日志面板“复制 SQL”都用 `host::copy_to_clipboard`；
  用户拒绝时按钮返回 denied 错误，其余功能不受影响（工作台仍可选中 SQL 文本手工复制）。
- 视图消息（`views.post-message`）是宿主对已声明视图的调用面，不单列能力；
  若 `openidea-plugin check` 报未授予，再补 `views.post-message` 到 required。

## i18n 键（已落在 `src/i18n.rs`，供 L8/L9 复用）

  `view.workbench.*`（13 个，含置信度 exact/partial/unresolved/unknown）。
- 依赖车道键：L2 的 7 个 `params.*`；L4 的 10 个 `log.*`（与
  `core::log::message_keys` 常量逐项对齐，测试钉住）。
