## 跑器契约（供 CI / 主控调用）

```text
cargo test --test cases_parity          # 全量对拍（含白名单机制自检）
cargo test --test cases_parity -- --nocapture   # 打印 cases/passed/whitelisted 与逐例 diff
```

- 汇总行：`cases: N, passed: N, whitelisted: M, failed: F | kinds: …`。
- 任一未豁免差异 → 测试红，并打印 `id` 与 expected/actual。
- 白名单条目在用例转为全绿后会被判为 stale 并变红，避免豁免长期滞留。
- `whitelist_is_exercised_and_documented` 断言白名单 ≥5 条且每条有理由
  （证明机制被真实使用，而不是空跑）。
- `case_inventory_is_sane` 断言 id 唯一且 8 个 kind 都有覆盖。
