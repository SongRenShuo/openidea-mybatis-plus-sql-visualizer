# L37 注册申请：SQL 预览就地入口（hover provider）

本车道给「SQL 预览」补一个**就地入口**：鼠标停在 mapper 语句 id、`<sql>` 片段、
`<resultMap>` 或 Java mapper 方法名上，平台 hover 直接弹出渲染好的 SQL 卡片。

OpenIDEA 1.15 没有插件可触达的富内容弹窗，原版 IntelliJ 的 `SqlPreviewDialog`
在本端口无法复刻；平台 `hover` provider（API 1.3，返回 Markdown）是达成「就地
预览」的最近路径，渲染链仍是 `core::xml`，差别只有外壳。

`plugin.toml` 由主控独占，本车道未改；以下片段由主控在 `chore: 注册汇总` 时一次性应用。

## 1 `plugin.toml` — 新 provider kind

`hover` 是 API 1.3 起的能力（本仓 `engines.openidea = "^1.15"`，满足）。
声明为独立 provider 条目，语言 `xml` + `java`（Java 侧只对 mapper 方法名作答）：

```toml
# SQL preview on hover (L37): a mapper statement id / Java mapper method name
# shows that one statement, rendered through core::xml.
[[contributes.providers]]
kinds = ["hover"]
languages = ["xml", "java"]
```

> 不要把它并进现有的 `kinds = ["definition", "line-markers"]` 条目：并进去也能跑，
> 但 hover 是 L37 的独立开关面，单独一条便于日后按需停用。

## 2 能力（capabilities）

**不新增任何能力。** 读取目标 mapper 文件走 `Project::read_file`，归属已有的
`required = ["project.read", "events"]`（`project.read` 的注释已写明「render and check
statements against the project's mapper XML」）。不需要 `fs.read`（项目内文件不走
`host::fs`）。

## 3 `src/lib.rs` — 可选导出

`hover` 走独立的 `plugin-hover` world，需要在宏里补一项：

```diff
 register_plugin!(
     Main,
     views,
     indexing,
     providers,
     injections,
     inlay_hints,
     diagnostics,
     language_features,
+    hover,
     mcp
 );
```

（`src/providers/mod.rs` 的 `pub mod hover;` 本车道已自行加。）

## 4 `src/i18n.rs` — 新增文案键

卡片外壳文案走 `i18n::t()`（跟随 IDE 语言）；渲染原因沿用工程约定
`[message_key] detail`，不额外翻译 core 的 message key（与工作台
`view.workbench` 的 `reason_lines` 一致）。

| key | en | zh-CN |
| --- | --- | --- |
| `hover.title.sql` | SQL | SQL |
| `hover.title.fragment` | SQL fragment | SQL 片段 |
| `hover.title.resultmap` | Result map | 结果映射 |
| `hover.title.method` | mapper method | Mapper 方法 |
| `hover.fragment.used_prefix` | Included in this file: | 本文件内被 include： |
| `hover.fragment.used_suffix` | time(s) | 次 |
| `hover.resultmap.type_prefix` | Maps to | 映射到 |
| `hover.resultmap.extends_prefix` | Extends | 继承自 |
| `hover.resultmap.used_prefix` | Used by statements in this file: | 本文件内被语句引用： |
| `hover.sql.truncated_prefix` | SQL truncated; showing the first | SQL 已截断，仅显示前 |
| `hover.sql.truncated_suffix` | characters | 个字符 |
| `hover.java.ambiguous_prefix` | Found | 找到 |
| `hover.java.ambiguous_suffix` | candidate mapper statements; cannot choose one. | 处候选 Mapper 语句，无法确定唯一一条。 |

`locales/*.json` 无新增：本车道没有新的命令 / 菜单 / 设置项标题需要清单本地化。

## 6 触发范围与卡片形态

| 文档 | 光标位置 | 卡片 |
| --- | --- | --- |
| mapper XML | `<select\|insert\|update\|delete>` **起始标签内**（`id` 值、元素名、任意属性） | 该语句的 SQL，首行 `**SQL** · \`exact\`` |
| mapper XML | `<sql id="…">` 起始标签内 | 片段 id + 本文件内 `<include>` 次数（0 次也如实显示） |
| mapper XML | `<resultMap id="…">` 起始标签内 | `type` / `extends` + 本文件内被语句引用数；三者皆无则不出卡片 |
| Java | mapper 接口方法名（UTF-16 命中标识符） | 同 `namespace`+`id` 的唯一 XML 语句渲染结果 |
| Java | 方法名、但索引里命中多处 | `Found N candidate mapper statements; cannot choose one.`，不给 SQL |
| 其它 | 任意 | `None`（不制造空白卡片） |

语句正文（SQL 文本节点）**不触发**：光标在 body 上返回 `None`。这样「悬停看 SQL」
只在标识符/标签上有反应，正文编辑不弹卡。

### 置信度

- `exact`：首行 ``**SQL** · `exact` ``，紧跟 ```` ```sql ```` 代码块；
- `partial`：首行 ``**SQL** · `partial` · `xml.include.not_found` ``（原因摘要），
  仍然给 SQL；
- `unresolved`：首行 ``**SQL** · `unresolved` ``，**不给 SQL 块**，只给
  `[message_key] detail` 原因行（例如 `[xml.parse.failed] …`、
  `[include.cycle] …`），与 `docs/ARCHITECTURE.md` 的「unresolved 不出 SQL」一致。

### 长度与安全

- SQL 长度沿用 `log.maxSqlLength`（默认 20000，下限 256），超长按字符边界截断，
  卡片尾部注明「SQL 已截断，仅显示前 N 个字符」；
- SQL 放进围栏代码块，围栏长度取 SQL 内最长反引号串 + 1（至少 3），SQL 里出现
  反引号也不会提前闭合围栏；
- 原因里的 `detail` 先折叠空白、再包成内联代码 span（围栏同理加长），用户文本中的
  `*` / 反引号 / 换行不会改变卡片结构；
- 单条渲染，无全项目搜索；Java → XML 只做一次进程索引哈希查询 + 一次
  `Project::read_file`，在 provider 预算内（软 50 ms / 硬 500 ms）。

## 7 行为边界（写进 LIMITS 时可引用）

- Java 侧只认 **XML 语句**：`@Select` / `@Insert` 等注解式 SQL 本车道未接
  （不在任务口径内，作为未覆盖形态登记）；
- 同一 `(namespace, id)` 在多个 mapper 文件里出现时**不猜**，返回候选数；
- XML 侧一次只渲染当前文档的语句，跨命名空间 `<include>` 无法在本文件解析时
  降级为 `partial`（与 `render_statement` 的单文档语义一致，卡片会标
  `xml.include.not_found`）；
- 同一文件内重复 `id` 时 `render_statement` 无法唯一定位，卡片为 `unresolved`
  （`xml.statement.not_found`）；MyBatis 本身也不允许重复 id。
