# 项目架构总览

> 本仓是 IntelliJ 版 `mybatis-plus-sql-visualizer` 的 **OpenIDEA 端口**。两者共享同一套 SQL 语义与同一个引擎 jar，
> 但平台能力不同（无 PSI、无类型解析、`database` 不执行 SQL），所以**分层按 OpenIDEA 的约束重画**，
> 不照搬 IntelliJ 版的 Swing 分层。
>
> 最后核对：2026-11-26（对应 HEAD `87e31f9` 之后的文档提交）。

## 1 产品定位

把 MyBatis 生态里的四类输入还原成**可直接执行的 SQL**，并在执行前给出风险与性能提示：

| 输入 | 输出 |
| --- | --- |
| Mapper XML（`<select>/<update>/<insert>/<delete>` + `<if>/<foreach>/<set>/<where>`） | 可执行 SQL + 参数占位 + `confidence` |
| Wrapper 链 / 注解 SQL / iBatis | 同上（经引擎 jar 的文本解析） |
| 运行日志（`Preparing:` / `Parameters:` / `Total:` / `Updates:`） | 批量还原、分类（慢查询/N+1/重复/错误） |
| 表结构描述（JSON） | CRUD 模板、回滚计划（快照 + 反向 SQL） |

产品纪律只有一条：**不猜**。每条结果带 `confidence`（`exact` / `partial` / `unresolved`）；
`unresolved` 不出 SQL，只给原因和补充入口。

## 2 分层架构

依赖只允许自上而下；反向依赖通过 `host::` 能力回调，不许跨层直连。

| 层 | 目录 | 职责 | 允许依赖 |
| --- | --- | --- | --- |
| L1 触发层 | `src/commands/`、`src/providers/`、`src/indexer/`、`src/injections/`、`src/inlay_hints/`、`src/diagnostics/`、`src/mcp/` | 把平台的命令/上下文菜单/编辑器事件/MCP 调用转成一次调用 | L2、L3、`core` |
| L2 编排层 | `src/capture/`、`src/sidecar/`、`src/execute/` | 捕获通道（文件/WebSocket/agent）、引擎进程与协议、EXPLAIN 请求装配 | L3、`core`、`host::` |
| L3 领域核心 | `src/core/` | 纯逻辑：XML 解析、条件求值、SQL 分类、参数回填、方言、性能规则、CRUD/回滚生成、日志解析 | 无（只依赖 `serde` 等基础库） |
| L4 展示层 | `src/views/`、`web/` | 面板状态、页面协议、HTML/包页渲染 | L3、`host::views` |
| L5 引擎边界 | `engine/`（只有版本与哈希）+ 外部 jar | 文本级 Wrapper 渲染、日志回填、方言表、EXPLAIN 包装 | 仅经 `src/sidecar/` 调用 |

`src/core/` 是唯一允许写「SQL 语义」的地方。它不碰 `host::`，因此可以在 `cargo test` 里跑全量、被 `cases/` 夹具驱动。

## 3 目录与依赖

| 目录 | 职责 | 禁区 |
| --- | --- | --- |
| `src/commands/` | 13 条命令的薄壳：取参 → 调 `core` → 写 Output | 不做解析、不做格式化 |
| `src/core/` | 纯函数领域层（`annotation/` `dialect/` `format/` `r#gen/` `ibatis/` `log/` `params/` `perf/` `xml/`） | 不调 `host::`、不读文件 |
| `src/views/` | 两个面板的宿主侧状态与协议（`log_panel.rs`、`workbench.rs`） | 不拼 SQL、不做判定 |
| `web/` | 包页（自包含 HTML/CSS/JS，只用 `--openidea-*` 变量） | 不引外链、不用 `innerHTML` 拼 SQL |
| `src/capture/` | 日志捕获：控制台/文件、WebSocket 客户端、agent 桥 | 不解析日志格式（交 `core::log`） |
| `src/sidecar/` | 引擎进程生命周期、`--stdio` JSON 行协议、请求/响应类型 | 不嵌入引擎源码 |
| `src/providers/` | 编辑器 provider（补全、悬停、引用等） | 单次预算 50 ms 软 / 500 ms 硬 |
| `src/indexer/` | `documentIndexers`：Mapper 语句索引 | 不做 PSI 查询（平台无 PSI） |
| `engine/` | `ENGINE_VERSION` + sha256，唯一允许的引擎引用形态 | 不放 jar 本体 |
| `icons/`、`locales/`、`settings.schema.json` | 资产、本地化、设置 schema | 图标 ≤16 KiB、禁 `foreignObject` |

## 4 运行时组件注册

声明式清单 `plugin.toml` 是唯一注册面（命令、视图、菜单、设置、providers、indexer、MCP 工具、javaAgent、
markerIcons、fileIcons）。代码侧只有一个入口：

```rust
register_plugin!(Main, views, indexing, providers, injections, inlay_hints, diagnostics, mcp);
```

要点：

- 清单声明**先于**代码可用：命令出现在 Find Action、菜单/状态栏可点、设置页存在，都在 wasm 首次加载之前。
- 能力（capability）分 required / optional；新增 required 会让已 link 的插件**静默不加载**，改 required 前先提醒用户重新授权。
- `java.agent` 由 `[[contributes.javaAgents]]` 派生，属于高风险可选能力；拒绝时保留「读日志文件」这条降级路径。
- `[[contributes.views]]` 的 `web = "…"` 表示包页；不写 `web` 才是代码绘制（`Body::Html`）。

## 5 关键设计决策

1. **双路径**：XML/日志走仓内 `core`（可测、离线）；Wrapper/注解/JPA 与 EXPLAIN 走引擎 jar（复用 IntelliJ 版已验证的解析器）。
2. **引擎不复制**：只认 `engine/ENGINE_VERSION`（版本 + sha256），由 `process:java` 启动；版本不匹配或起不来就**降级纯文本**并在 UI 明示，绝不跑错版本。
3. **面板用包页，不用代码绘制 HTML**：包页的 `openidea.postMessage` / `onMessage` 通道实测可用；代码绘制的 `Body::Html` 在 0.1.51 上「页面 → 宿主」消息未到达（见验收文档 D1），因此两个面板都走 `web =`。
4. **状态在宿主、渲染在页面**：宿主持有行/筛选/暂停等状态并推 JSON；页面只建 DOM（`textContent`），不拼 HTML，避免注入与状态漂移。
5. **置信度先于可用性**：`unresolved` 的语句不出 SQL，避免「看起来能用其实错」。
6. **能力可选、降级明确**：`clipboard` / `process:java` / `net:127.0.0.1` 全部 optional，缺哪个就只关掉对应按钮或退回文件路径。

## 6 速查：从入口到代码

| 想找 | 去哪 |
| --- | --- |
| 命令 id → 处理函数 | `plugin.toml` 的 `[[contributes.commands]]` → `src/lib.rs` 的 dispatch → `src/commands/<name>.rs::run` |
| 一条 SQL 怎么被分类 | `src/core/log/classify.rs`（唯一分类入口） |
| 参数怎么回填 | `src/core/params/` |
| 性能规则 | `src/core/perf/rules.rs`（`rule_id` 与 `messageKey` 一一对应） |
| 日志格式解析 | `src/core/log/`（`Preparing/Parameters/Total/Updates`，多方言） |
| 面板数据从哪来 | `src/views/log_panel.rs` 的 store → `build_rows` → `post_view_message` |
| 页面协议 | `web/log-panel.html`、`web/workbench.html` 的 `post({op:…})` 与宿主 `handle_message` |
| 引擎调用 | `src/sidecar/proto.rs`（协议）+ `src/execute/`（EXPLAIN 包装） |
| 引擎版本 | `engine/ENGINE_VERSION`、`engine/ENGINE_VERSION.sha256` |
